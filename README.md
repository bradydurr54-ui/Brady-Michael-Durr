# Click Counter

A glowing, animated button that counts every click. Built with Python's
built-in `tkinter`, so there's nothing to install.

```
python3 click_counter.py
```

- Click the button to count (with a particle burst).
- Your count is saved to `.click_count.json` and survives restarts.
- Press **R** to reset.

> On Linux, if you get `No module named 'tkinter'`, install it with
> `sudo apt install python3-tk`.
